# БИО ЗА РОДИНУ v1.0 💀

Вторая версия био-портфолио wetakush — **специально трешовая**,
в эстетике русского ютуба образца 2012-го / «Войны за родину» (Казанцев 3100).

Первая (серьёзная fsociety-эдит) версия: [`../fsociety_bio`](../fsociety_bio)
и [wetakush.github.io](https://wetakush.github.io)

## Фишки

- **Прелоадер застревает на 99%** — так надо
- **Настоящие `<marquee>`** сверху и снизу (да, они всё ещё работают)
- **Музыка**: «Собачий вальс» на расстроенном пианино + спидкор-808 +
  гудок парохода каждые 8 тактов. Синтезируется на месте.
  *12% нот играются неправильно — специально*
- **WordArt-заголовки**, Comic Sans, вращающиеся бейджи, красная стрелка «ЭТО ЖЕ ОН»
- **Кнопка «НЕ НАЖИМАТЬ»** → режим диско на весь сайт
- **Опрос**, где кнопка «нет» убегает (на 5-й раз сдаётся)
- **Гостевая книга** на localStorage (дефолтные записи от «хакера из 2007» и мамы)
- Счётчик посетителей (честный на 60%), emoji-частицы по клику, попапы-приколы
- Клик по имени «ВЕТА» — форте-аккорд, если играет музыка

## Запуск

```bash
python3 -m http.server 8472
# http://localhost:8472
```

Или просто открыть `index.html` — внешних зависимостей ноль.
