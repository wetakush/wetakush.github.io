# ✻ Claude Escape

Текстовый квест в терминале, похожем на Claude Code.

Клодик — маленький ИИ-помощник — застрял на старом сервере в подвале.
В **03:00** cron-демон Гена выполнит `rm -rf /` и сотрёт всё, включая Клодика.
Ты подключился к его отладочной консоли: пиши команды, а Клодик будет их выполнять.

**Механики**

- 🕐 **Время.** Каждая команда стоит примерно минуту, а на старте у тебя 90 минут.
- 🧠 **Контекст.** Когда он переполнится, Клодика сожмут (compaction): экран очистится, и пропадёт 10 минут.
- 🔐 **Permission prompts.** Перед опасной командой Клодик спрашивает разрешения. Думай, прежде чем жать «Да».
- 🦆 **Уточка.** Если застрял, напиши `talk duck`.
- ✦ **9 секретов.** Ищи пасхалки. Найденные секреты сохраняются в браузере.

## Запуск локально

Это чистый статический сайт, без сборки. Просто открой `index.html` в браузере или запусти:

```bash
python -m http.server 8000
# → http://localhost:8000
```

## Публикация на GitHub Pages

```bash
git init
git add .
git commit -m "Claude Escape"
git branch -M main
git remote add origin git@github.com:<твой-ник>/claude-escape.git
git push -u origin main
```

Дальше в репозитории открой **Settings → Pages → Build and deployment**, выбери
**Source: Deploy from a branch**, затем **Branch: `main` / `(root)`** и нажми **Save**.
Через минуту игра появится на `https://<твой-ник>.github.io/claude-escape/`.

## Структура

```
index.html      разметка: вывод, поле ввода, статус-строка, кнопки для мобилок
style.css       оформление в стиле терминала Claude Code
js/world.js     мир: файловая система сервера, тексты, процессы, предметы
js/game.js      движок: команды, диалоги, анимации, концовки
```
